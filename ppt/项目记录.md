## 规格

- **风格**：B · 瑞士国际主义（Swiss Style）
- **主题色**：🔵 克莱因蓝 IKB（`#002FA7`），全篇单一锚点色
- **页数**：14 页 · 讲稿时长合计 14.2 分钟（＜20 分钟目标的 90%）
- **版式**：`data-layout` 全部取自 locked 清单 —— S03 / S04 / S05 / S11 / S12 / S13 / S14 / S16 / S17 / S19 / S20 / S22×3 + `SWISS-COVER-ASCII` / `SWISS-CLOSING-ASCII`
- **字号**：≤ 6vw 大字、≤ 8vw 巨字；最小字号守住 16px（meta 14px）

## 内容口径（不得改动）

- 数据来自云效「Hsp 2.0」真实议题：4 周 / 73 条 / 11 人 / 81% 已闭环，周度 5→8→24→33。
- 结果数据**不单独成页**，仅在收尾页一笔带过（作者要求）。
- 依赖门禁三句口径：等待不空转 · 失败不静默 · 成环不死锁。
- 不新增资料未列出的数字或百分比。

## 操作方式

| 操作 | 键 |
|---|---|
| 翻页 | `←` `→` / 滚轮 / 触屏滑动 / `空格` |
| 总览 | `ESC` |
| 演讲者模式 | `P`（含备注、计时、排练、观众屏同步） |
| 低功耗（停动效） | `B` |

演讲者模式备注按 `data-slide-id` 存在 `localStorage`，页面重排不会串页。

## 重新生成

```bash
python ppt/tools/make-images.py   # 重做 3 张证据图（从 docs/ 截图裁 21:9）
python ppt/tools/build.py         # 组装 ppt/index.html
node ppt/tools/probe.cjs          # 生成量版副本（配合 Edge --dump-dom 量溢出）
```

内容编辑改 `ppt/tools/slides.html`（页面）与 `ppt/tools/notes.js`（备注），
模板基座是 `ppt/tools/template-swiss.pristine.html`——**不要直接改 `ppt/index.html`**。

## 校验

```bash
node <SKILL>/scripts/validate-swiss-deck.mjs ppt/index.html
node <SKILL>/scripts/validate-presenter-mode.mjs ppt/index.html --target-minutes 20
```

两项均通过（14 slides / 14 notes / 0 errors）。
另用 headless Edge 实测 14 页：**底部溢出 0px，无内容触及分页安全线**。

## 已知取舍

- 本环境 Google Fonts 不可达，故 Inter 改为自托管 woff2；中文回落到 PingFang SC / 微软雅黑。
- 模板说明文档里列的 S15/S16 若干卡片类（如 `brief-grid`、`matrix-fill`）在模板 `<style>` 中并不存在，
  本 deck 只用模板里**确实有定义**的类，缺的部分在构建脚本里以 `.nz-*` 私有类补齐（直角、无阴影、单一 accent）。
- `ppt/.shots/` 为本地渲染校验产物，可随时删除。
