# Nezha v0.29.0 发版公告

Nezha v0.29.0 正式发布！本版本围绕**云效交付闭环**持续深化：交付计划的双向回写补全了「计划开始时间」，云效议题列表新增彩色状态徽章与多维度筛选，并支持需求 / 缺陷类型区分。

## 🚀 新特性

### 交付计划（delivery-plan）

- **计划完成时间回写**（`4cf101c`）：把议题加入交付计划时，自动将「计划完成时间」回写到云效；移出计划时同步清空，保持两侧一致。
- **计划开始时间回写**（`d75f42e`）：加入计划时默认写入当天作为「计划开始时间」（云效工作流切「待开发」时该字段必填，缺失会 400），移出计划时一并清空。
- **字段解析通用化**：「计划开始 / 完成时间」两个日期字段共用同一套字段 ID 解析与缓存（缓存 key 含字段名），后续扩展更多日期字段零成本。

### 云效集成（yunxiao）

- **彩色状态徽章**（`1b6d88c`）：议题状态按语义着色，一眼区分进行中 / 已完成 / 待处理。
- **产品与计划完成时间筛选**（`1b6d88c`）：工具栏新增两个筛选维度，配合搜索快速圈定议题范围；工具栏同步重组布局。
- **需求 / 缺陷类型徽章**（`c1f619b`）：移除「任务」类别，新增需求 / 缺陷类型徽章，与云效工作项体系对齐。

### 设置（settings）

- **项目级 prevent_auto_commit 开关**（`09b413a`）：新增项目级开关，阻止自动提交行为，按项目粒度控制。

## 🐛 问题修复

- **云效列表加载更多**（`3f2d405`）：产品筛选激活时「加载更多」按钮不再消失，分页浏览恢复正常。

## 📝 文档

- 新增「方案并行执行（worktree 并行 × 滚动合并 × 增量统一构建）」需求文档 v1（评估中，未实施）（`e836f09`）。
- PPT 中知识沉淀流程文案更新为「产出 → 四层质量门 → 暂存 → 审核发布」链路（`8c33e2e`）。
- 新增 `.zcodeignore` 供 ZCode 工具链使用（`a6d28c4`）。
