# Nezha v0.39.0 发版公告

Nezha v0.39.0 正式发布！本版聚焦 **Codex structured 会话体验**与 **Windows 中文环境输出乱码修复**，共包含 1 个新特性、3 个问题修复和 1 项 UI 打磨。

## 🚀 新特性

### Codex 会话（codex）
- **会话 Markdown 里的 `file://` 本地文件链接可以直接点击打开了**（`61a3b5b`）：此前 structured 会话正文中智能体生成的本地文件链接一律提示「暂不支持」。现在点击后会还原本地路径并交由系统默认应用打开（如 `.html` 用默认浏览器）。仅限实际存在的文件；网络路径（UNC）、目录和无法解析的链接仍保持不可点。

## 🐛 问题修复

- **中文 Windows 下终端回显乱码**（`03ea4c4`）：中文 Windows 的系统代码页是 GBK（936），智能体执行 PowerShell/cmd 子命令时输出的 GBK 字节此前按 UTF-8 误读，回显成「鏁版嵁搴」这类合法但错误的汉字。现在采用双层策略：spawn 侧为 Python 子进程注入 `PYTHONUTF8` 预防，解码侧按活动代码页（GBK/Big5/Shift_JIS/EUC-KR）兜底重解，UTF-8 合法时绝不改写。终端读缓冲、写切片等性能红线结构未动。已知边界：agent 自身把字节替换成 U+FFFD 的场景无法恢复，需上游修复。
- **终止 structured 任务后，流式条目永远显示「执行中」**（`46b956c`）：通过 `/stop`、ESC 或取消终止任务时，正在执行的命令、文件修改、MCP 工具调用收不到上游完成帧，终端分组一直显示「executing」且计时无限跳动。现在任务进入终止态时会立即收尾所有未完成条目：进行中的翻转为失败、计时冻结，与底部「任务已停止」状态一致。
- **切换任务再回来，「工作中 · N 秒」计时从 0 重跳**（`015da1e`）：流式工作指示器的计时起点原来是组件挂载时刻，重挂载即归零。现在锚定到数据里本轮实际开始时刻，切回任务后首帧即显示真实已工作时长。

## 🎨 界面打磨

- **任务列表状态图标简化为色点**（`b9be346`）：任务状态图标收敛为统一的彩色圆点样式，视觉更轻量、与整体界面语言一致。
