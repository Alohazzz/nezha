# Nezha v0.38.0 发版公告

Nezha v0.38.0 正式发布！本版本主题是**视觉与阅读体验升级**：新增两款全新暗色主题、Mermaid 图表直接渲染、会话文档链接可点击、Codex 工具卡片改为跑马灯流式，另有依赖安全升级。

## 🚀 新特性

### 主题（theme）

- **新增 zinc 与 claude dark 两款暗色主题**（`4ae7102`）：从 paseo 移植的两款暗色变体——zinc 是无色相的锌色阶梯配近白色单色强调色，claude dark 则是暖色表面配 Claude 橙强调色。两款都沿用「侧边栏比内容区深一档」的双层表面模型，左栏与内容区边界清晰。主题面板升级为 2×3 网格，终端配色、代码高亮（shiki）、文件查看器等派生色全部同步适配。
- **侧边栏整体下沉一档**（`4e9f5bd`）：采纳 paseo 的双层表面模型——内容区保持最亮表面，侧边栏族（左栏、任务面板、右侧面板、标题栏）统一沉一档，四种主题下都有可见边界。此前 midnight 主题所有表面共用同一个 `#1a1b1d`，零对比度。同时把三个浮动弹层（文件搜索下拉、文件右键菜单、评审评论右键菜单）改用 `bg-card`，保证浮层比页面亮。

### Mermaid 图表渲染（markdown）

- **代码块直接渲染为图表**（`a68a0cb`）：会话消息、Codex 流视图、云效计划预览、codeup 评审报告中的 ```mermaid 代码块（含 `mermaid` / `mmd` 围栏及无语言标注的 flowchart 风格代码块）现在直接渲染为图表，解析失败回退为纯文本展示，带体积/复杂度预算防护。图表支持点击放大预览、缩放与拖拽平移，配色随主题明暗自动切换。

### 会话文档链接（codex）

- **正文链接可点击**（`97ef352`）：structured 会话正文里智能体引用的产物文档（discussion.md / knowledge.json 等）和项目内路径此前是死链接，只能手动翻文件树定位。现在点击即按项目根与 worktree 解析，在右侧文件查看器打开并自动切分栏布局；支持 `:行号` 后缀，外部链接走系统浏览器，文件缺失给出 toast 提示。安全边界不变：能打开的前提仍是文件读取命令的项目根内路径校验。

### 工具卡片流式（codex）

- **跑马灯流式展示**（`3676e52`）：命令、文件变更、MCP 工具、协作代理卡片与思考卡对齐——运行中不再自动展开、完成后不再自动折叠，最新一行输出通过摘要行的跑马灯持续滚动（尾部跟随 + 边缘淡出），完整输出保留在手动展开区。同时修复卡片从「无输出」翻转为「有输出」时正文意外弹开的泄漏。

## 🐛 问题修复

- **预览对话框按钮拖拽后失灵**（`eb7e23d`）：Mermaid 放大预览对话框在拖拽平移后，缩放 / 适配 / 关闭按钮点不动——指针捕获吞掉了从按钮上起始的按下事件。现在按下发生在按钮上时跳过捕获；另外 ctrl+滚轮缩放改用非被动原生监听，`preventDefault` 真正拦住浏览器页面缩放。

## 🔒 安全与依赖

- **pulldown-cmark 升级到 0.13.5**（`61888f5`）：修复 RUSTSEC-2026-0414（`ENABLE_WIKILINKS` 下事件数指数增长，严重度 7.5）。nezha 只启用删除线/表格/任务列表，漏洞路径未启用，仍按补丁级直接升级消除审计告警。

## 📝 文档

- 本版新增 5 个测试文件，覆盖 Mermaid 代码块识别、Codex 正文链接解析、命令卡跑马灯尾部跟随、文件变更卡与可折叠翻转回归、主题与终端配色扩展。
