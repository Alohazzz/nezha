# Nezha v0.36.0 发版公告

Nezha v0.36.0 正式发布！本版本主题是**Codex 结构化运行通道**：新增基于 codex app-server 的结构化接入（issue #116），任务不再只有终端 TUI 一种形态——流式卡片、可折叠工具调用、可视化 diff、可交互 composer 全部就位，同时保留原有的终端模式作为默认与回退。

## 🚀 新特性

### Codex 结构化运行通道（codex）

- **app-server 协议客户端**（`94125ac`）：新增独立的 `codex_appserver` 模块，实现 JSON-RPC 帧处理、待响应请求表、通知事件解析、审批决策映射与会话生命周期管理（含进程优雅退出、Windows 无窗口启动、版本地板 0.156 握手校验）。该模块与任务系统解耦，PTY 链路零改动。
- **任务系统结构化接入**（`802001f`）：`Task.runMode` 字段（`types.ts` 与 `storage.rs` 同步）落地，`run_task` 按运行通道分流，结构化事件经 IPC Channel 直投前端，取消 / 完成 / 重置 / 活跃任务查询全部适配，并新增审批应答命令。
- **结构化流式视图**（`25fdbf4`）：按任务粒度维护帧合并模型，沿用 ref buffer + RAF 批量更新（与终端同一套抗高频渲染策略，绝不在每条 delta 上 setState）。五类卡片（消息、思考、命令、文件变更、MCP）与审批卡、用量条一并实现，样式全部走 `styles/codex-stream.ts`，无行内样式。
- **结构化降级与版本门控**（`e86eb9d`）：结构化启动失败（进程拉起 / 握手 / 首轮 turn）时自动降级回终端重跑并提示，任务快照自愈回 `pty`，后续视图、恢复、续聊全部切回终端语义；新增版本预探测，低于 0.156 时设置项直接给出不可用提示。
- **验证版本**：Claude Code / Codex 两条通道共用同一套提示词组装（项目前缀、禁自动提交、文本附件、知识沉淀契约）与环境变量注入，结构化路径在生产语义上与终端等价。

### 运行模式设置（settings）

- **运行通道改为应用级设置**（`97028eb`）：通用设置新增「Codex 运行模式」下拉（终端 / 结构化），取代原先的任务级选择器；旧的选择记忆会一次性迁移。结构化受 Codex 版本门控，检测不到可用版本时自动回落到终端。
- **云效任务同样跟随全局设置**（`401443e`）：云效直接开始、待办直接开始、发起讨论、合并讨论、方案执行此前分流不一致，现在全部由 `codex_run_mode` 决定；结构化路径补齐了提示词组装、`NEZHA_*` 与知识图谱环境变量注入、真实项目路径校验、任务名登记，以及收尾时的草稿汇总与知识沉淀。

### 结构化流视图（codex）

- **不可变合并层**（`6199139`）：把帧到模型的合并逻辑抽为纯模块，delta 追加改为生成新对象，被 memo 的卡片终于能感知每次增量；新增 revision 计数供下游判断增长，5000 条目上限、乱序占位、权威完成替换等既有语义全部保留（spec #117）。
- **统一工具卡骨架**（`0dc8db7`）：五类卡片共用一套摘要行（图标 / 分类标签 / 主文本 / 元信息 / 状态），支持展开状态跨任务切换与重挂载保留、运行中自动展开并在完成时自动收起（手动操作优先生效）、失败原因悬浮提示与复制。
- **渲染器注册表**（`2933be0`）：不再用 switch 硬编码，新增未知上游条目会渲染带类型徽标和原始 JSON 的调试卡，而不是一片灰色占位；MCP 调用区分入参与结果，文件变更默认收起并接入自动展开节奏。
- **可视化差异视图**（`d613a8a`）：解析 unified diff 与上游结构化文件变更，先以纯文本着色快速绘制、再异步 Shiki 高亮（主题跟随四种应用主题，过期结果自动丢弃）；单文件单卡，多文件父卡 + 子卡，超过 2000 行可一键跳转到右侧 Git 变更面板。
- **命令输出尾部截断**（`b453bbc`）：命令卡只渲染输出尾部（约 64KB，按整行边界），标注省略行数并提供「复制完整输出」，完整内容仍保留在内存中。
- **实时耗时与展开节奏**（`35be859`）：思考卡运行中持续跳动、完成后定格总时长；命令卡运行中显示实时秒数，完成后替换为权威耗时；分类标签补齐四语言国际化（issue #119）。
- **命令分组与摘要精简**（`f2e0f90`）：连续命令合并为单个「终端」行并显示条数，运行时只显示当前执行的那条；自动剥离 `bash -lc` / `pwsh -Command` 等外壳包装，展开后仍可看到并复制原始命令；成功状态词不再占用摘要行。
- **结构化行文本对比度**（`5456445`）：新增按主题分层的标签 / 元信息 / 图标色板，四种主题下对比度全部达到 WCAG AA 以上（原先浅色与护眼主题最低仅 2.4:1）。
- **整轮工作中指示器**（`0699576`）：长思考或长命令导致增量静默时，流尾常驻「工作中 · N 秒」与旋转指示，避免看起来像卡死。
- **多智能体调用渲染**（`29032bb`）：`collabAgentToolCall` 不再显示为「未知条目类型」的原始 JSON 调试卡，改为展示动作标签、参与数量、实时耗时和逐智能体状态；同时携带上游真实失败原因，并把失败横幅固定在滚动区之外，长任务失败后也能立刻看到原因。
- **图片灯箱**（`9eef276`）：composer 附件与用户消息气泡中的缩略图支持点击放大，Esc / 点击遮罩 / 关闭按钮均可退出；该灯箱与新建任务页共享。

### Composer 交互（composer）

- **双模 composer**（`481ea8f`）：运行中与等待输入时提交即向当前回合注入消息（`turn/steer`），完成 / 中断 / 失败后提交则恢复会话开新回合；所有任务状态都保留输入框，审批待处理时自动禁用；提交后立即显示乐观用户气泡。带会话文件的已结束结构化任务继续展示流视图，不再退回 JSONL 回放。
- **中断与内置命令**（`948f2fa`）：新增停止按钮、Esc 中断与 `/stop`，只中断当前回合而不杀会话，中断后任务标记为「已中断」可继续；取消按钮保留更强的结束会话语义。新增 `/compact`（压缩上下文）与 `/review`（代码评审）内置命令。
- **`$` / `/` / `@` 快捷召唤**（`2d8a318`）：统一输入触发模块——`$` 召唤技能、`/` 召唤智能体自定义命令、`@` 引用项目文件，支持过滤与键盘导航。结构化续聊框接入全部三种，新建任务页沿用同一套 `$` 技能逻辑。后端新增 `list_agent_commands`，扫描 `~/.claude/commands`、`~/.codex/prompts` 及项目级目录。
- **图片附件**（`1c9c0b1`）：结构化 composer 支持粘贴与选择图片（issue #118），缩略图可移除、纯图片可发送；图片落盘到任务附件目录并以 `localImage` 输入项随回合下发，首轮启动、后续注入、上游回放、乐观气泡、降级重跑全部打通，附件与终端模式同目录同清理。
- **模型与思考深度选择**（`1054a20`、`bcf8771`、`1c3e191`、`c09f6ba`）：`/model` 与 `/effort` 打开选择浮层并写入应用级设置，此后所有结构化任务的启动与续跑都携带该覆盖；运行中的会话仍会热更新，下一回合生效；清空或选择「默认」即回到跟随 Codex 默认模型。composer 底部显示当前模型徽标。

## 🐛 问题修复

- **续聊后历史被清空**（`6192ab0`）：向已结束的结构化任务继续对话时，恢复流程不会回放历史消息，而此前会先重置流模型，导致对话历史丢失。现在续聊只清理过期的用量与审批状态，保留既有条目；恢复失败也不再清空视图。
- **续聊出现重复用户气泡**（`cb75049`）：本地乐观气泡与上游回放的同内容消息 ID 不同，此前会并存两条。现在上游消息落地时按内容剔除尾部重复的本地气泡，内容不同则保留以防误删。
- **结构化任务永远是 `task-<id>` 名字**（`4a8201d`）：结构化会话不写 Codex 的会话索引，自动命名永远查不到。现在索引未命中时从任务提示词派生首版名称（取首个非标题行、剥离命令前缀与 Markdown 装饰、截断 60 字符），终端任务仍优先使用 Codex 自己的命名。
- **崩溃后残留的完成态无法继续**（`01324d1`）：应用强退后结构化任务可能停留在虚假的「已完成」，现在按「已中断」收口，续跑改走结构化恢复而不是终端队列，并补充完整性回归测试。
- **差异高亮死循环与工具卡边界问题**（`a93d9ed`）：修复 diff 视图在识别到语言扩展后反复高亮导致的无限渲染循环，以及纯文本行误用 HTML 渲染、失败提示按钮嵌套、空输出卡片仍可点击等一批边界问题。
- **Vue 解析测试在 CI 上偶发退化**（`7127686`）：强制 Vitest 对 CodeMirror / Lezer 模块去重，恢复被临时弱化的断言，消除同一逻辑时过时不过的抖动。
- **RustSec 新公告卡住 CI**（`31e495f`）：升级 zstd 系列修正可用告警，并为被 Codex 上游依赖锁死、或需跨大版本升级的告警补充带复审说明的审计豁免。
