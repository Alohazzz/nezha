# Nezha v0.40.0 发版公告

Nezha v0.40.0 正式发布！本版聚焦阅读体验：任务完成后的未读提醒、Codex 流式会话的视觉打磨与问题卡折叠、mermaid 图文件直接渲染预览。

## 🚀 新特性

### 任务列表（agent）
- **已完成任务未读蓝点指示**（`70be4b7`）：任务进入 done/failed 终态时置 unreadAt 时间戳（正观看中豁免，每轮完成重新置位），列表项亮蓝点并加粗标题，项目切换器头像左下聚合蓝点，一眼看到哪些任务在你离开后有了结果。显式点选任务即清除并持久化；存量任务缺省视为已读，不加状态枚举值。*（Fixes 未读遗漏场景）*
- **mermaid 图文件渲染预览**（`8c15dd9`）：`.mmd` / `.mermaid` 文件在文件查看器中直接渲染为图表，不再只看源码。复用 markdown 预览的渲染管线（主题感知配色、串行渲染队列、纯文本兜底、放大弹窗），SVG 自适应铺满预览窗格；可随时通过预览/编辑按钮切回 CodeMirror 源码视图。

### Codex 流式会话（codex）
- **多题确认卡可折叠**（`d6ee75e`）：确认卡此前以 60vh 常驻 sticky 底部，题目多时把会话内容全部盖住。现在点击标题条可收起成一行（保留跳过入口），新请求到达自动展开、手动收起不抢开；高度封顶降到 50vh 并按内容自然收缩。带选项题的「其他」自定义输入框收进伪选项默认不占位，无选项的自由输入题保持常驻。

## 🐛 问题修复

- **会话链接含中文文件名打不开**（`23bea82`）：marked 渲染 markdown 时会对非 ASCII 链接目标做百分号编码，中文文件名（如 `Dy开发技能最佳实践.html`）到达点击处理器时变成了 `Dy%E5%BC%80....html`，按原文解析永远找不到文件。现在剥离 `:line` 后缀后先解码再解析，畸形序列回退原始值。
- **流式工作中指示器不可见**（`ebbdf12`）：stream 尾部的 working 指示器此前以 0x0 尺寸渲染——组件用 class 而 CSS 只带了 spin 关键帧，样式表里还留着两份从未被引用的重复样式对象。现在布局外壳与 spinner 尺寸统一定义在 CSS，动画改为 spin + breathe；并在长命令（如 2 分钟安装）无输出增量时，在运行段过程区尾部钉一个内联 loader，视觉焦点处始终有活着的信号。
- **未读蓝点未与标题对齐**（`e01bd25`）：蓝点从 flex 子项改为标题行内 inline 元素，随文字基线垂直居中，与「已完成」状态行同轴对齐，不再浮在卡片左上角。
